
# [PRD] AI 계약서 리스크 검토 서비스: "안심계약 AI (가칭)"

## 1. 제품 개요 (Product Overview)

* **비전:** 법률 사각지대에 있는 프리랜서와 소상공인이 독소 조항으로부터 스스로를 보호하고, 대등한 위치에서 협상할 수 있도록 돕는다.
* **핵심 가치:** 전문성(정확한 리스크 탐지), 접근성(쉬운 용어 풀이), 신속성(PDF 업로드 후 30초 이내 결과).
* **타겟 사용자:**
* 디자인, 개발 등 용역 계약을 앞둔 프리랜서.
* 상가 임대차 또는 가맹 계약을 진행하는 소상공인.



## 2. 주요 기능 (Key Features)

### 2.1. PDF 계약서 업로드 및 텍스트 추출

* **설명:** 사용자가 보유한 PDF 또는 이미지 형태의 계약서를 업로드.
* **상세 요구사항:**
* 멀티페이지 PDF 지원.
* Gemini의 멀티모달 기능을 활용하여 별도의 OCR 엔진 없이 직접 문서 맥락 파악.



### 2.2. 독소 조항 탐지 및 리스크 등급 분류

* **설명:** 업종별 표준 계약서와 대조하여 사용자에게 불리한 조항을 식별.
* **등급 체계:**
* 🔴 **위험:** 법적 효력이 의심되거나 일방적으로 불리한 조항 (예: 지식재산권 무상 귀속).
* 🟡 **주의:** 모호한 표현으로 분쟁 소지가 있는 조항 (예: 무제한 수정 요구).
* 🟢 **안전:** 표준 약관을 준수하는 조항.



### 2.3. 안전한 대안 문구 추천 (Side-by-Side)

* **설명:** 탐지된 위험 조항을 어떻게 수정해야 하는지 구체적인 가이드라인과 대안 문구 제시.
* **상세 요구사항:**
* "기존 문구" vs "추천 문구" 비교 뷰 제공.
* 해당 수정을 요구해야 하는 논리적 근거(법적 근거/표준약관 근거) 설명 포함.


### 2.4. '쉬운 설명' 번역 기능

* **설명:** 복잡한 법률 용어(한자어, 일본식 표현 등)를 일상적인 언어로 풀어서 설명.

## 3. 사용자 흐름 (User Flow)

1. **홈:** 서비스 소개 및 '내 계약서 검토하기' 버튼.
2. **업로드:** 파일 업로드 및 업종/계약 유형 선택 (예: 디자인 용역, IT 개발, 임대차).
3. **분석 중:** 애니메이션과 함께 Gemini API 호출 및 분석 진행.
4. **결과 리포트:**
* 종합 위험도 점수.
* 항목별 리스크 리스트.
* 대안 문구 확인 및 복사하기.


5. **저장/공유:** PDF 리포트로 다운로드하거나 결과 링크 공유.

## 4. 기술 스택 (Tech Stack)

* **Frontend:** React.js 또는 Next.js (SEO 및 빠른 초기 로딩 대응).
* **Backend:** Python (FastAPI 또는 Flask) - LangChain 및 AI 로직 처리에 최적화.
* **AI 모델:** **Gemini 1.5 Flash** (속도 및 비용 효율성) 또는 **Pro** (복잡한 논리 분석용). (사용 가능한 모델에 따라 변경 가능)
* **Database:** Supabase 또는 Firebase (빠른 MVP 구축용).
* **Infrastructure:** Vercel 또는 AWS.

## 5. 데이터셋 활용 계획

* **참조 데이터:** AI-Hub의 '계약 법률 문서 서식' 및 공정거래위원회 표준약관.
* **방식:** RAG(검색 증강 생성)보다는 **System Prompt**에 주요 표준 조항 가이드라인을 주입하거나, PDF 전체를 컨텍스트로 넣는 **Long Context Window** 전략 사용.

## 6. 성공 지표 (Success Metrics)

* **핵심 지표:** 사용자가 업로드한 계약서 1건당 평균 분석 소요 시간 (목표: 30초 이내).
* **만족도:** 분석 결과의 정확도에 대한 사용자 긍정 피드백 비율.
* **전환율:** 결과 확인 후 '대안 문구 복사' 버튼 클릭률.

3. **친절한 마이크로카피:** "어려운 계약서, AI가 대신 읽어드릴게요"와 같이 딱딱하지 않은 말투 사용.
